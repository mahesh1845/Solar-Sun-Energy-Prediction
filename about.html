About SolarCast

A machine-learning web app that predicts solar power generation from weather conditions.

How it works

You enter temperature, humidity, solar irradiation and wind speed. A scikit-learn regression model trained on dataset.csv predicts the power output in kW. Daily energy is estimated as power × peak sun hours, and from that we compute bill savings and CO₂ reduction.

Features

  • Real-time prediction from user input, with predicted power (kW) and daily energy (kWh)
  • Interactive dashboard, prediction history and CSV report download
  • Power generation graph, weather visualisation, daily / weekly / monthly analytics
  • Actual vs predicted comparison and model accuracy (R², MAE, RMSE)
  • Panel efficiency estimation, best time to generate, performance analysis
  • Low generation alert, high temperature warning, recommendations
  • Estimated electricity bill savings and CO₂ emission reduction

Tech stack

HTMLCSSJavaScriptPythonFlaskscikit-learn

Assumptions

  • Simulated system: 5 kW array, 28 m² panel area (used for efficiency).
  • CO₂ factor 0.82 kg per kWh (approximate Indian grid average).
  • The included dataset is synthetic. Replace dataset.csv with real measurements (columns: temperature, humidity, irradiation, wind_speed, power_kw) and run python train.py.
